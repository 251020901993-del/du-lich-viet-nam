WEBSITE HTML/CSS CO BAN - CHU DE KHAM PHA VIET NAM

1. CAC FILE TRONG THU MUC
- index.html: Trang chu.
- gallery.html: Trang bo suu tap (co 6 hinh anh).
- tips.html: Trang meo du lich.
- style.css: File dinh dang duoc dung chung cho ca 3 trang HTML.
- images/: Cac hinh minh hoa dang SVG, duoc luu ngay trong may nen co the mo website khi khong co mang.

2. CACH MO TREN MACBOOK
- Tai file ZIP va giai nen.
- Mo thu muc Website_Du_Lich_CSS3.
- Nhan dup vao index.html de xem trang chu tren trinh duyet.
- Bam cac muc Trang chu, Bo suu tap, Meo du lich tren thanh menu de mo cac trang khac.
- Neu muon sua ma, mo cac file .html va style.css bang VS Code hoac mot trinh soan thao van ban.

3. CAC YEU CAU DA DUOC AP DUNG
- Ca 3 trang deu lien ket den cung mot file style.css.
- Moi trang co lien ket "Chuyen den noi dung chinh"; lien ket nay chi hien khi duoc focus (vi du nhan Tab).
- Thanh dieu huong duoc tao bang Flexbox, co mau nen, khoang dem, bo goc va hieu ung hover.
- Trang chu va bo suu tap su dung CSS Grid.
- Trang meo du lich su dung Flexbox de xep anh va noi dung canh nhau.
- Hinh anh co vien, padding va border-radius.
- Co hieu ung :hover va bo chon :nth-child().
- Trang gallery.html co 6 hinh anh; moi trang deu co it nhat mot hinh anh.
- Co alt text mo ta hinh anh va lien ket CSS tuong doi style.css.

4. KIEM TRA TRUOC KHI NOP
- HTML: vao https://validator.w3.org/ , chon File Upload hoac Validate by Direct Input va kiem tra tung file HTML.
- CSS: vao https://jigsaw.w3.org/css-validator/ va kiem tra file style.css.
- Accessibility: mo https://wave.webaim.org/ va nhap URL website sau khi ban da dua web len mang. Website mo bang file tren may chua co URL cong khai.
- Neu giang vien yeu cau gui lien ket, ban can dang cac file len mot dich vu host website, vi du GitHub Pages.

Luu y: Cac hinh SVG trong thu muc images la hinh minh hoa tu tao cho bai tap. Ban co the thay bang anh chup cua minh, nhung nho giu dung ten file hoac sua lai duong dan src trong HTML.
